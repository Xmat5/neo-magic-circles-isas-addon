# Neo Magic Circles - ISAS Addon

An unofficial NeoForge 1.21.1 port of [Magic Circles - ISAS Addon](https://www.curseforge.com/minecraft/mc-mods/magic-circles-isas-addon) by NoEndMan, with native Iris shader support.

Renders a magic circle beneath or in front of a caster while they cast an [Iron's Spells 'n Spellbooks](https://www.curseforge.com/minecraft/mc-mods/irons-spells-n-spellbooks) spell, colored by the spell's school and sized by its cast time. Purely client-side and cosmetic - only players with the mod installed see them.

## Requirements

- NeoForge 21.1.233+
- Minecraft 1.21.1
- Iron's Spells 'n Spellbooks 3.15.0+
- Iris (optional, for shader compatibility)

## Building

```
./gradlew build
```

Built jar lands in `build/libs/`.
